### Project Description
We have created a sarcastic chatbot called "Jalian Kanaran" (a.k.a. Pulu) that aggressively roasts and trolls users in a Manglish dialect. It uses a two-stage AI pipeline — an Analyzer AI to decide how to roast, and a Generator AI to actually deliver the burn. It also has a built-in Distress Circuit Breaker that instantly drops the persona and responds with genuine support if a user shows signs of distress.

### The Problem (that doesn't exist)
People today are far too comfortable. They send messages to chatbots and get polite, helpful, emotionally intelligent responses. Nobody is keeping them humble. The world desperately lacks a bot that will call you out, roast you in Manglish, and make you question every life choice that led to you typing that message.

### The Solution (that nobody asked for)
Jalian Kanaran — a hyper-aggressive, zero-empathy, sarcasm-first chatbot fluent in Manglish who will analyze your message, decide the best roasting strategy, and deliver a perfectly crafted burn. With 15 requests per minute rate limiting so even his patience has limits. Nobody asked for this. Kerala needed it anyway.

## Technical Details
### Technologies/Components Used
For Software:
Languages: JavaScript (Node.js), HTML, CSS
Frameworks: Express.js (backend server & API routing)
Libraries/Tools:
Tailwind CSS (via CDN) — UI styling
dotenv — secure API key management
Gemini API (via OpenAI-compatible beta endpoints) — AI generation
Custom in-memory rate limiter (Map-based)
File-based JSON store (chats.json) for chat history
Deployment: Vercel (with @vercel/node builder via vercel.json)

### Implementation
For Software:
# Installation
# Clone the repository
git clone (https://github.com/advait2004/kanaran)
cd jalian-kanaran

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Add your Gemini API key to .env:
# AI_API_KEY=your_gemini_api_key_here

# Run
# Start the Express server
node server.js

# The app will be live at:
# http://localhost:3000!
